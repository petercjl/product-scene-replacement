# 替换执行与恢复

产品替换固定使用 `@petercjl/sealseek-media-cli` 的 `nano-banana-pro`。以 `sealseek-media skill source --json` 解析同名配套 Skill，完整读取其当前 `SKILL.md`，按其中的当前 Agent 绑定和实体安装启动器运行。缺失依赖时报告 `DEPENDENCY_MISSING` 并指向其安装说明。

调用配套 Skill 发现实时能力和认证状态，再检查 `models show nano-banana-pro --live --json`。每轮使用 `image generate --model nano-banana-pro` 的参考图模式，按顺序传入原场景和所选资产图，指定单张输出。按当前模型合同选择画幅和分辨率。先 dry-run，在实际生成授权范围内提交一次，并按真实任务 ID 跟踪及取回本地图片，再回主流程验收。固定模型不可用或无法满足关键参考条件时，报告具体缺口并暂停生成。

执行前在项目外部工作记录中保存场景蓝图和已锁定的输入哈希。每轮写新记录并在提交前保存实际输入顺序、提示词和预算，回执到达后绑定真实任务 ID 或宿主调用记录。中断或结果未知时先查原记录及原任务；仅在确认没有待恢复提交且仍有授权预算时推进。恢复时校验输入版本，保留历史结果。

验收分别记录产品、场景、接触、遮挡与文字；不适用项写明原因。技术成功只表示图片已返回。业务失败时保存结果和差异，修订下一轮提示词或参考选择。场景的原始内容一直由原场景承担，上一轮成品用于对照验收。没有达标图时交付真实状态及主要差距。
